# Java Programming Technologies

Серия из пяти последовательных лабораторных работ, в ходе которых поэтапно разрабатывается система управления питомцами (котиками) и их владельцами — от консольного приложения до микросервисной архитектуры с брокером сообщений.

## Стек технологий

| Область | Технологии |
|---|---|
| Язык и платформа | Java 17 / 21 |
| Сборка | Maven, Maven Wrapper |
| Фреймворки | Spring Boot, Spring MVC, Spring Data JPA, Spring Security, Spring AMQP |
| Доступ к данным | Hibernate ORM, JPA, PostgreSQL |
| Обмен сообщениями | RabbitMQ |
| Тестирование | JUnit 5, Mockito, MockMvc, Spring Security Test |
| Документация | JavaDoc |
| CI | GitHub Actions |
| Прочее | Lombok |

## Запуск

Параметры подключения к БД и брокеру задаются через переменные окружения (значения по умолчанию в конфигурации — заглушки):

| Переменная | Назначение |
|---|---|
| `DB_PASSWORD` | пароль PostgreSQL |
| `RABBITMQ_USERNAME`, `RABBITMQ_PASSWORD` | учётные данные RabbitMQ (ЛР-5) |
| `ADMIN_PASSWORD` | пароль администратора при первом запуске (ЛР-5) |

Сборка модуля: `mvn package` в каталоге соответствующей лабораторной работы.
